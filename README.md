## Описание
Todolist — это минималистичный одностраничный список задач. Простая логика позволяет:
- Добавлять задачи,
- Помечать выполненные,
- Удалять задачи,
- (Опционально) Фильтровать и сохранять в LocalStorage.

Проект отлично подходит как заготовка для обучения JavaScript, практики с DOM API и базовыми паттернами фронтенда.

## Особенности
- Простая статическая реализация: достаточно `index.html`.
- Возможность сохранить данные в LocalStorage (если подключён JS).
- Поддержка мобильных и десктопных экранов при корректной вёрстке.
- Лёгкая кастомизация стилей и логики.

## Требования
- Любой современный браузер (Chrome, Firefox, Edge, Safari).
- (Опционально) Python/Node для запуска локального dev‑сервера, если хотите тестировать относительные пути или fetch.

## Установка и запуск локально

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Baxa2367/Todolist.git
cd Todolist
```

2. Откройте `index.html` двойным кликом в файловом менеджере — сайт откроется в браузере.

3. Рекомендуемый способ (локальный HTTP‑сервер) — для корректной работы относительных путей и возможных модульных скриптов:
- С Python:
```bash
python -m http.server 8000
# Откройте http://localhost:8000
```
- С Node (http-server):
```bash
npx http-server -c-1
# Откройте http://localhost:8080
```

## Использование
- Введите текст задачи в поле ввода и нажмите Enter или кнопку "Добавить".
- Чтобы пометить задачу выполненной — нажмите чекбокс / кнопку рядом с задачей.
- Для удаления — нажмите кнопку удаления (иконка корзины/крестик).
- Если реализовано сохранение в LocalStorage — список будет восстановлен после перезагрузки страницы.

Советы по UX:
- Старайтесь делать большую цель разделами — краткие задачи легче выполнять.
- Добавьте возможность редактировать задачу при клике.

## Кастомизация и расширение
- Стили: правьте CSS (встроенный или `assets/css/styles.css`).
- Логика: правьте JavaScript (`assets/js/app.js`), разделив логику на функции:
  - addTask(text)
  - removeTask(id)
  - toggleTaskCompleted(id)
  - saveTasks() / loadTasks()
- Разделите DOM‑логику и хранение данных — это облегчает тестирование.
- Добавьте валидацию ввода (не добавлять пустые задачи).
- Добавьте подтверждение перед удалением для предотвращения случайных действий.

## Сохранение/синхронизация данных
Варианты хранения задач:
1. LocalStorage (простая, офлайн, только на одном устройстве):
```js
localStorage.setItem('todolist', JSON.stringify(tasksArray));
const tasks = JSON.parse(localStorage.getItem('todolist') || '[]');
```
2. Backend API (синхронизация между устройствами): реализуйте REST API (используя Node/Python/etc.) и добавьте fetch-запросы.
3. Firebase / Supabase: быстрый облачный вариант с аутентификацией.

Рекомендации:
- Шифруйте/не сохраняйте чувствительные данные.
- Для серверного хранения оборачивайте API защитой (аутентификация).

## Доступность и оптимизация
- Используйте семантическую разметку: `<header>`, `<main>`, `<section>`, `<ul>`, `<button>`.
- Все интерактивные элементы должны быть доступны с клавиатуры (tabindex, обработка Enter/Space).
- Добавьте aria-атрибуты: `aria-label`, `role="button"` для пользовательских элементов.
- Оптимизируйте изображения, минимизируйте CSS/JS при продакшене.
- Тестируйте с инструментами: Lighthouse, axe.

## Тестирование и отладка
- Для логики, вынесенной из DOM, можно писать unit‑тесты (Jest, Mocha).
- Для e2e тестирования UI используйте Cypress или Playwright.
- В браузере используйте DevTools для отладки JS/стилей и проверки LocalStorage.
